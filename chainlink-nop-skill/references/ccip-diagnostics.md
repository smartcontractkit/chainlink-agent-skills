# CCIP node diagnostics

**Returned** means an error propagated to a caller; **log** means text emitted by the node. Every emitted signal below describes this node's local execution only: it does not establish fleet-wide impact, another node's state, or a deeper root cause beyond the stated boundary.

## Direct warning, error, and critical signals

| Severity | Exact emitted message | Important fields | Local condition and one-node boundary |
|---|---|---|---|
| Warning | `failed to get home chain contract reader, retrying. if this is consistently happening please check home chain RPC health` | `attempt`, wrapped `err` | On this node, home-chain reader creation or binding failed, including capability lookup or CCIP configuration-contract binding. It retries indefinitely every 10 seconds. The RPC-health suggestion does not prove an RPC root cause. |
| Error | `Failed to tick` | `err` | On this node, a launcher tick failed because the home-chain reader was not ready, the capability-registry diff failed, or a DON add/update/remove action failed. The monitor continues at the next tick; this log does not identify the nested cause without `err`. |
| Error | `Some oracles failed to be created` | `donID`, `err` | This message has two lifecycle call sites on this node. During update, a member DON's changed digest could not produce an oracle, commonly through `oracleCreator.Create`; during add, digest conversion or oracle creation failed after the non-member gate. That DON update/add is skipped for the pass. A preceding `getConfigsForDon` failure does not use this message. |
| Error | `Failed to shutdown don instances after a failed start` | `donId`, `err` | On this node, `StartAll` failed and its compensating `CloseAll` also failed. This reports cleanup failure, not the original start failure; the start error is returned and can later appear under `Failed to tick`. |
| Error | `transmitter contains invalid UTF-8` | `transmitter`, `relayID.Network`, `chainSelector` | On this node, the first transmitter supplied for a CCIP-supported provider failed UTF-8 validation. Oracle creation aborts with a returned error and may surface through the lifecycle logs above; this does not prove other CCIP configuration is valid or invalid. |
| Warning | `contracts transmitter provided from CCIP provider is nil, will use default transmitter if possible` | `relayID`, `chainSelector` | On this node, a provider supplied a chain accessor but no contract transmitter. Exec may later use the destination chain-writer transmitter, or fall through to a no-op transmitter; the warning alone does not show which path was selected. |
| Warning | `CCIPProvider codec has no SourceChainExtraDataCodec` | `chainSelector` | On this node, the provider codec has no source-chain extra-data codec, so none is registered for that chain family and setup still succeeds. It does not prove a later message will require that codec. |
| Warning | `Unknown observation metric` | `metric` | On this node, the publisher received a name other than `ocr3_sent_observations_total` or `ocr3_included_observations_total`; no Beholder counter is incremented for that call. It does not imply that observation processing failed elsewhere. |
| Critical | `no-op transmitter FromAccount() called, it shouldn't be! Check the CCIPHome ChainConfig for this chain and ensure the 'readers' field is correctly set` | `myP2PID` | On this node, OCR unexpectedly asked a role-DON no-op transmitter for its account. Check this chain's CCIPHome `ChainConfig.readers`; the method still returns its configured fake account and `nil`, and the log does not establish another node's transmitter state. |
| Critical | `no-op transmitter Transmit() called, it shouldn't be! Check the CCIPHome ChainConfig for this chain and ensure the 'readers' field is correctly set` | `myP2PID`, `configDigest`, `seqNr` | On this node, OCR unexpectedly attempted transmission through a role-DON no-op transmitter. Check this chain's CCIPHome `ChainConfig.readers`; the method returns `nil`, and the log does not prove report validity, destination-chain acceptance, or another node's transmission outcome. |

## Returned errors and lower-severity context

These entries provide setup and configuration context without treating returned-only errors as emitted warning/error/critical messages.

| Diagnostic | Exact node signal or expected behavior | Boundary and meaning |
|---|---|---|
| **Job setup: P2P, keys, and relayers** | **Returned:** `failed to make peer ID from provided spec p2p id (%s): %w`; `failed to get all p2p keys: %w`; `OCRKeyBundleIDs must be a map of chain types to OCR key bundle IDs, got: %T`; `OCR key bundle with ID %s not found: %w`; `error parsing chain ID, expected big int: %s`; `error getting enabled addresses for chain: %s %w`; `error getting all keys: %w`; `unsupported network: %s`; or `failed to parse bootstrapper locators: %w`. Successful lookup/enumeration does not prove DON membership, and transmitter enumeration may return an empty slice without error. | The job's `CCIPSpec` drives the specified P2P key, OCR bundles, configured relayers' transmitter keys, and bootstrap peer parsing. |
| **Registry relayer and syncer setup** | **Returned:** `could not fetch home chain relayer %s that is configured for capabilities registry: %w` or `could not create registry syncer: %w`. **Debug log:** `Received new state from syncer` records a listener callback; it is not a freshness or health guarantee. | The external-registry relay ID selects the relayer used to create the registry syncer and attach the launcher listener. |
| **Configured capability absent** | A possible `err` chain carried by `Failed to tick` is `failed to diff capability registry states: %w` → `failed to check capability presence: %w` → `failed to find capability with capabilityID %s in capability registry state`. The ID is `<label>@<version>` from the job; only DONs whose configuration map contains that capability are selected. | The job capability fields are matched against the launcher's `LocalRegistry` view. This is one possible tick failure, not the complete boundary of `Failed to tick`. |
| **Commit and Exec config reads** | **Returned:** `failed to fetch OCR configs for CCIP commit plugin (don id: %d) from home chain config contract: %w` or `failed to fetch OCR configs for CCIP exec plugin (don id: %d) from home chain config contract: %w`. Commit is read first, so its failure prevents the Exec read in that call. Zero digests are filtered; at most four configs remain: candidate/active for Commit and Exec. | The launcher obtains both plugin configurations through `HomeChain.GetOCRConfigs`. |
| **Expected non-member or bootstrap skip** | **Info logs:** updates emit `Not a member of this DON, skipping`; additions by a plugin creator emit `Not a member of this DON and not a bootstrap node either, skipping`. These branches return no deployment. A nonempty `P2PV2Bootstrappers` list selects the plugin creator; an empty list selects the bootstrap creator. | Local P2P ID and creator type determine whether the DON membership gate produces a local deployment. |
| **Active/candidate local deployment** | Up to four plugins represent `(active/candidate) × (commit/exec)`; only active plugins transmit while candidates dry-run. **Returned:** `current pluginRegistry or prevPlugins have more than 4 instances: len(prevPlugins): %d, len(currPlugins): %d`. | Home-chain configuration digests drive the local plugin-registry transition. |

The EVM, Solana, Aptos, Sui, and TON family adapters and the `validate`, `types`, and `ccipnoop` residual modules have no direct production warning/error/critical-or-stronger emissions. Returned-only adapter errors and messages from external dependencies are outside this emitted-log catalog.
